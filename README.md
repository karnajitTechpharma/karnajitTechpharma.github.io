# Karnajit Reang — Digital Portfolio

A responsive, single-page portfolio for pharmacy, pharmacovigilance and healthcare AI. It uses the supplied portfolio dataset and portrait, with a lightweight CSS 3D visual system and no build step or runtime dependencies.

## Run locally

Open `index.html` in a modern browser. For a local web server, run:

```sh
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish

Upload the project files to a GitHub repository. To publish it with GitHub Pages, open the repository’s **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. The site is static and needs no build command.

## Included

- `index.html` — page content and metadata
- `styles.css` — responsive layout, color themes, motion and 3D-inspired elements
- `script.js` — navigation, theme persistence, scroll reveals and portrait tilt
- `karnajit-reang.jpg` — optimized version of the supplied profile photo

The page intentionally omits the unfilled Class X and XII details and does not include a CV download because none was supplied. Research content is presented as an interest, not a publication or completed project.
